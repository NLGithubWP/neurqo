# Third-party baselines

The baseline implementations are based on their official releases.

| Method | Official repository |
|---|---|
| FASTgres | [db-tu-dresden/FASTgres-PVLDBv16](https://github.com/db-tu-dresden/FASTgres-PVLDBv16) |
| TONIC | [axhertz/TONIC](https://github.com/axhertz/TONIC) |
| GenJoin, HybridQO, AutoSteer | [edualc/genjoin](https://github.com/edualc/genjoin) |

Repository-local workload and measurement adapters are under
`scripts/reproduce/`; the upstream learning implementations remain in these
source trees.
